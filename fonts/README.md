# Fonts

`LiberationSans-Regular.ttf` and `LiberationSans-Bold.ttf` are Liberation Sans, version 2.1.5, taken unmodified from the official release of [liberationfonts/liberation-fonts](https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5) (the asset `liberation-fonts-ttf-2.1.5.tar.gz`, SHA-256 `7191c669bf38899f73a2094ed00f7b800553364f90e2637010a69c0e268f25d0`). The release publishes no checksums; both files were also compared byte for byte with the ones of the Fedora package `liberation-sans-fonts` 2.1.5.

The fonts are licensed under the SIL Open Font License 1.1 (`OFL.txt`), not under the licence of the rest of the repository. They are embedded whole in the program, with no subsetting or other change, which the licence allows for bundling with software. Liberation Sans has the metrics of Arial, which the original game asks for; no other font is used.
